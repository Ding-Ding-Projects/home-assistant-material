RULES
1A linked file is used like any other media file: in the media picker, in automations, on speakers and screens.
2It is fetched only when needed and removed after use. "Stored here: nothing" is always true unless Keep 10 min is chosen.
3Only the owner adds addresses. The home fetches only those addresses, with a size limit and a time limit.
4If the address does not answer, whatever asked for it gets a plain reason, and the row says when and why.
5An address with a password or key in it is kept hidden after it is added and never shown again.
