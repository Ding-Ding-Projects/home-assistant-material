RULES
1Going back makes a backup first. The "backup before updating" choice does not turn this off; only the super confirmation does, once, for that one going back.
2The older build is installed only after the backup is reported finished and its check passed. Failed, stopped, timed out or unknown all mean: do not go back.
3The rule is held by the system, not only by the page: asking to go back any other way gets the same backup first.
4If another backup is already running, going back waits for it and then makes its own.
5The history line says which backup was made: "Went back to build 525 at 21:56 · backup 21:54".
