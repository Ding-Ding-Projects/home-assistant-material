RULES
1The file holds names of integrations, where each came from, and the kinds of entity it makes. Never a sign-in, a key, an address, an option or a state.
2Names the owner gave are left out unless the owner turns them on. Counts can be turned off.
3The preview shows exactly what will be saved. Saving is a download in the browser; nothing is sent anywhere.
4Importing only compares. It installs nothing, sets up nothing and downloads nothing by itself.
5Set up opens the integration's own setup, one at a time. A row moves to Already here only when that setup really finished.
6An imported file is data. Unknown names are shown as text and never run, fetched or trusted; a file over 1 MB or of another shape is refused whole.
7Admins only, both ways. Buttons are 48 px tall and the three groups scroll sideways on a phone.
8One integration's settings: sign-ins are left out by default. With them, the file is always locked with the owner's password, behind the two keys. Values are never shown, logged or sent.
9A settings file only fits the integration it names. Importing shows every change first, names only, and applies nothing until the two keys and the slider.
10Before applying, the settings as they were are kept so Undo works. An import that the integration refuses changes nothing.
