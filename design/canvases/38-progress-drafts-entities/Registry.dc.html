RULES
1Public is expected here, because it is free. So the lock is not optional: no password, no upload. There is no switch to turn it off.
2The password is typed twice, must be long, and is never stored or sent. Only the key made from it stays on this system.
3Everything is locked at home before it leaves: the video, the backups, and the names, dates and sizes that would say what they are.
4The page says plainly what public means: anyone can copy the locked files and keep them for ever, and a forgotten password cannot be recovered.
5One repository by default; any camera and backups can have their own.
6An older recording plays straight from the registry: fetched in parts, unlocked here, playing before the whole file has arrived.
7The local copy is removed only after the registry confirms the upload, and a test opens one bundle again before the place is trusted.
8The registry may remove what is not a container image, or slow down heavy use. The page says so, and this is never the only copy unless you choose that.
