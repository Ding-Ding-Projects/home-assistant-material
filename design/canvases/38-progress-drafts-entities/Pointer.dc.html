RULES
1Off until the owner turns it on, and only where the registry place is set up with its password.
2The copy on this disk is replaced only after the registry copy was read back and every part checked. Failed, unknown or "did not answer" keeps the whole copy.
3The newest backup is always kept whole by default, so one restore works with no network. The owner may choose none or three.
4A pointer holds no key and no password: only which backup it is, where it is, its size and its check value.
5Pointers are checked against the registry each day. A missing copy turns the row red; it is never shown as a backup that can be restored.
6Counts are honest: "whole here" and "pointer" are counted apart, and a pointer is never called a local backup.
7A delete proof backup keeps its mark as a pointer: neither the pointer nor the registry copy can be deleted. The backup made before going back is kept whole until that going back has finished.
8Said plainly on the page: with only pointers, losing the registry account or the password means losing those backups.
