Your own wording fileSeen workingLanguage
A JSON file of your own words replaces the shipped wording everywhere text is shown. It is checked in full first (size, nesting, duplicate and unsafe keys, lengths, control characters); a file that fails changes nothing. Only the checked entries are kept, in this browser.On this page: Settings, Your wording. Choose a file, or drop it anywhere on the page. The same checks as the product run here.
