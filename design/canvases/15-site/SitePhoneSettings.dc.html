Your wording

Your wording fileNo file yet. A JSON file with schemaVersion 1 and entries replaces words on this page.
Default: No file. What it reaches: Every label and text on this page, in this browser only

You can also drop the file anywhere on the page. It is checked in full before anything changes: at most 256 KiB, nesting depth 8, keys up to 160 characters and values up to 1000, no duplicate or unsafe keys, no control characters. A file that fails changes nothing. Nothing about the file is sent anywhere.
