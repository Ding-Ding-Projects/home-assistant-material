Home Assistant in Material Design 3

The same home automation, with a calmer interface: a floating pane, a slim rail, large type and fewer, larger cards. Built from one repository, released for Docker, Raspberry Pi and virtual machines.

Every search field has a button that opens a regular expression workbench: build, test, explain, and use the pattern.

A menu on every element

Edit the appearance of any element

Right-click any element and change its colour, background, corners, size and weight, beside the element, with undo per change.
