Home Assistant in Material Design 3

The same home automation, with a calmer interface: a floating pane, a slim rail, large type and fewer, larger cards. Built from one repository, released for Docker, Raspberry Pi and virtual machines.

Run it in DockerReleases

Run it

One container for amd64 and arm64. Then open http://<host>:8123.

docker run -d --name homeassistant --restart unless-stopped --network host -v /path/to/config:/config ghcr.io/ding-ding-projects/home-assistant-material:latest

One step, with Docker Compose

Clone the repository and run host.bat on Windows or ./host.sh on Linux and macOS. It pulls the image, starts it, waits until it answers and prints the address for this machine and your network.

What is built

Pictures from running builds. Most of the design is not built yet; the status page says exactly what is and is not done.

Pattern workbench on every search

Every search field opens a workbench for regular expressions: building blocks, a live test, replace, performance checks and code to copy.

Tools on any element

Right-click, Shift F10 or the menu key on anything: edit its appearance, copy its text, read it aloud, or lock it as a speed bump for fun.

Your own appearance, per element

Pick any element and change its colour, shape and type. Changes stay in this browser and can be undone from its history.

The whole design is in the repository

Every page, dialog and feature is drawn as a board, phone and wide window, light and dark. A board is a proposal until it is seen in a running build.
