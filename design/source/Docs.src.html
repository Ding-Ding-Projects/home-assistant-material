Lock an element

Any card, tab or setting can have its own lock. A locked element still shows its state, but its controls do nothing until you unlock it.

Add a lock

Right-click the element and choose Lock this element…, or press Ctrl Shift L. Pick what opens the lock, then set each part.

@@I:ImageOutline.l@@Screenshot from the running app goes here

Each lock keeps its own PIN, password and codes. There is no master key. See also Locked out and Pair an authenticator.
