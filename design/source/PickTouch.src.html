Choosing an element by touch

Audit 3: the pick tool previews on hover; on touch the first tap selected blindly. Decision: tap to outline, then confirm.

What this board settles

  • @@I:CheckCircle.s@@First tap outlines and names; a second tap on the same element, or Edit this, confirms. A tap elsewhere moves the outline.
  • @@I:CheckCircle.s@@Bigger and Smaller walk the element tree one level, so a small part or a whole section can be chosen.

Works differently from today's build

  • @@I:CheckCircle.s@@Hover preview stays for mouse users; on touch the confirm step is required.
  • @@I:CheckCircle.s@@The instruction bar is a status message, read out when the tool starts.
