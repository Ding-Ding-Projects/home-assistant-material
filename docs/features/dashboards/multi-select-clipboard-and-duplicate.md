# Multi-select, shared clipboard and duplicate

Built in batch 52 for dashboard editing.

- Select many cards at once (sections views). Masonry views are not covered yet.
- A clipboard shared between browser tabs, so cards copied in one tab can be pasted in another.
- Duplicate a view, or a whole dashboard.
- A Dashboards card, listing dashboards.
- On a phone, swipe sideways to move between dashboards.

## Limits and failure modes

- Multi-select works in sections views only for now.

## How it was verified

Unit tested. Not seen in a browser. State: built, unit tested, not yet seen in a running build.
