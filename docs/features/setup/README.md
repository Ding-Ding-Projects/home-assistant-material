A setup wizard here means real controls for every value, live checking as you type, a review of
what will be written, Back and Next, and a clear end state. Which wizards also have save and
resume, jump to a step and a test of the new value has not been confirmed for each; see the
"Interactive wizard" item in `../../HANDOFF.md`.
