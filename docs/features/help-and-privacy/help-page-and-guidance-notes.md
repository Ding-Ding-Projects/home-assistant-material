# Help page and guidance notes

Built in batch 48.

## Help page

A Help page for the offline help bundle (see `offline-help.md`): articles, integration pages
and images all ship with the interface, so reading them sends nothing and works without a
network.

## Guidance notes

Integration setup dialogs show a short note that says what a step needs and what it will do,
before the person fills in anything.

## Limits and failure modes

- The bundled articles carry their licence notice (`frontend/public/static/help/LICENSE-NOTICE.md`).
