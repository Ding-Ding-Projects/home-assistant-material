## Try the sample dashboard

Open the [interactive dashboard](https://ding-ding-projects.github.io/home-assistant-material/demo/#/lovelace/home)
in a browser. Focus **Toggle Floor lamp** and press Space to turn the sample lamp off. Press
Space again to restore it to 70%. Open the dashboard menu with Enter and close it with Escape.
These controls act on sample data in the browser.

The project website also carries both complete articles. Read the
[action dictionary guide](../features/automations/visual-action-dictionaries.md)
or the [dashboard editing guide](../features/dashboards/visual-configuration.md).
